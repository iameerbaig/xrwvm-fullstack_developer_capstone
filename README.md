# xrwvm-fullstack_developer_capstone

## Project Name
Best Cars Dealership Review Application

A full stack application for browsing car dealerships and posting reviews.

**Repository name:** xrwvm-fullstack_developer_capstone
**Project name:** Best Cars Dealership Review Application

## Tech Stack
- Django (backend, REST endpoints)
- React (frontend SPA)
- Express + MongoDB (dealer and review data service)
- Flask + NLTK (sentiment analysis microservice)
- Docker and Kubernetes (deployment)
